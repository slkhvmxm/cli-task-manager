# 📋 Task Manager

Простой и эффективный менеджер задач на **Go** (Golang).  
Поддерживает создание, просмотр, обновление и удаление задач через командную строку или REST API.

---

## ✨ Возможности

- ➕ Создание задач с заголовком, описанием и дедлайном
- 📋 Просмотр всех задач и фильтрация по статусу (выполнена/не выполнена)
- ✏️ Обновление статуса, заголовка или описания
- 🗑️ Удаление задач по ID
- 💾 Хранение данных в памяти / файле / базе данных (выберите своё)
- 🚀 Поддержка параллельной обработки (горутины + каналы)
